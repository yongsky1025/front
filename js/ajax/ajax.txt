AJAX(Asynchronous JavaScript And XML)
- 비동기적으로 정보(XML, JSON(주로 사용)) 교환
- 초창기 XMLHttpRequest 객체를 사용함 => jQuery 라이브러리 사용
- Fetch API(그냥 사용 가능) / axios 사용(설치)

객체: 중괄호({})로 시작하고 끝나며, 이름-값 쌍("name": "value")의 모음으로 구성됩니다. 각 쌍은 쉼표(,)로 구분합니다.
예시: {"name": "Alice", "age": 30}

json배열: 대괄호()로 시작하고 끝내며, 순서화된 값들의 목록입니다 [20]. 값들은 쉼표(,)로 구분합니다.
예시: [1, 2, 3, "apple"]
    [{"name": "Alice", "age": 30}, {"name": "Alice", "age": 30},{"name": "Alice", "age": 30}]
값의 종류:
문자열("text"),
숫자(100),
불리언(true, false),
null, 객체({}), 배열(``)을 사용할 수 있습니다.
